【中国地方】研磨材の調達ガイド：法規制と適合（JIS/JANSI）

中国地方（広島・山口）造船業向けの研磨材適合基準を整理します。JIS・JANSI（日本砥石工業会）照合の確認表、ラベル表示項目、適合・通関の責任区分を造船所の受入実務に沿って解説します。

墨泰研磨材·2026年11月21日

結論：広島・山口の造船所が研磨材の適合管理をするとき、決めるべきは「JIS・JANSI（日本砥石工業会）のどちらの基準で照合するか」です。当社は当地に在庫・拠点・法人・専属代理店を持たず、中国工場から（海上輸送 7〜15 日で）出荷するため、規格適合の最終判断は輸入者（購入者）の責任で締めます。

造船所の受入実務で見る適合の 3 層

造船所の工具受入は 3 層で機能します。第 1 層は規格照合（JIS・JANSI 基準で受入するか）、第 2 層は表示照合（ラベルに粒度・基材・安全情報が載るか）、第 3 層は文書照合（適合証明書・分析証明書・ロット追跡）。層ごとに受入者側で固定しておくと、船体製作の工程変更と工具受入が同期しやすくなります。

照合規格の選び方：JIS と JANSI

JIS は JISC が維持する工業規格で、ISO 系規格と交差する項目もあります。JANSI（日本砥石工業会）は研磨材業界の実務基準・制度で、適合保持の体制・範囲は未記載の点があり発注時に確認してください。造船所がクラス協会等の追加要件を課す場合は、それらも同表で管理します。

造船・船舶業界ページの作業分類を数量設計に使い、品質保証ページの証書要件を照合します。作業時の PPE と集じん・製品ラベル遵守を前提にしてください。確認表を確定するには見積依頼フォームから受入基準・必要証書・納品先（広島・山口の港湾）をお送りください。

受入チェック表：照合規格（JIS / JANSI）／粒度表記（FEPA P / JIS / ISO 6344）／ラベル表示項目／必要証書（COC・COA）／ロット追跡。未定項目は発注時に確認します。

よくある質問

造船所の受入で JIS 規格の適合証明が必要です。研磨材の JIS 適合は製造側での保持・未記載の区分があるため、必要であれば発注時に確認してください。適合の有無・範囲の最終判断は輸入者が行います。

粒度表記は JIS と FEPA P で統一できますか。FEPA P / JIS / ISO 6344 の表記で粒度区分が定義されます。表記を固定するとラベル照合が簡潔になります。採用する表記は購入者が決めます。
