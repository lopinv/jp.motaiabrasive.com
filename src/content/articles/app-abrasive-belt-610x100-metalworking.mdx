<p class="bluf"><strong>結論：</strong>610×100 mm を金属仕上げで使う場合、砥粒は被削材（軟鋼・硬鋼・ステンレス・アルミ合金）ごとに落とし込みが変わります。大半の中型仕上げ作業の開始点はグレード 80 で、素材の荒さで 40〜60、面出し済み部品なら 120 以上から入るのが妥当です。このモデルは砥粒 40〜800 の 12 グレードが揃うため、被削材ごとの段階設計を 1 サイズで回せます。</p>

<h2>被削材ごとに砥粒帯を落とす</h2>
<p>金属の表面には酸化物除去・バリ取り・塗装の 3 目的があり、砥粒の落とし込みは被削材の硬度と表面状態（保護層処理済みか）で決まります。</p>
<table class="spec-table">
  <thead><tr><th>被削材</th><th>開始の目安</th><th>注意点</th></tr></thead>
  <tbody>
    <tr><td>軟鋼</td><td>80</td><td>切りやすく進みが速い。120〜180 で面出し</td></tr>
    <tr><td>硬鋼</td><td>80（粗目重視）</td><td>厚い層の除去で短サイクル</td></tr>
    <tr><td>ステンレス</td><td>80〜120</td><td>砥粒の鈍化が早いためグレード帯の維持が重要</td></tr>
    <tr><td>アルミ合金</td><td>120 目安</td><td>砥粒詰まりに注意。金属種共有で推奨</td></tr>
  </tbody>
</table>
<p>出口はどの被削材も 400〜800 の超仕上げ帯に収まります。金属仕上げの選定軸（金属硬度・光沢要求・保護層状態）は<a href="/industries/metalworking">金属仕上げ向けソリューション</a>に整理しています。段階区分は<a href="/resources/abrasive-grit-guide">砥粒度選定ガイド</a>が基準になります。</p>

<h2>基材の選定：金属では剛性が効く</h2>
<p>このモデルの基材は紙・布・ポリマー繊維の 3 系統です。金属の安定した研削ではポリマー繊維系の剛性が追従性より優先され、エッジの平滑化のような柔軟性が欲しい場面で布系が使われます。基材の最終確定は購入者との確認事項なので、金属種と機械の負荷を共有いただくと推奨を提示します。ジョイント方式は生産前に機械指定と照合してください。</p>

<h2>金属発注書の書き方</h2>
<p>金属仕上げの見積依頼では、次の項目を書くことで推奨の精度が上がります。</p>
<ul>
  <li>被削材の金属種（軟鋼 / 硬鋼 / ステンレス / アルミ合金）。</li>
  <li>使う段階（研削 / 面出し / 超仕上げ）と砥粒グレード。</li>
  <li>機械タイプ（中型ベルト機）とジョイント方式。</li>
  <li>数量・注文頻度、必要証書（COC / COA）。</li>
</ul>
<p>金属タイプと要求仕上げグレードに基づいて砥粒タイプを決定し、サンプル送付または試験グレード提案後に数量注文へ進む流れは <a href="/products/models/abrasive-belt-610x100">製品ページ</a> の照合で確認できます。作業は PPE と粉塵の配慮、製品ラベルと機械マニュアルに従い行ってください。</p>

<div class="info-box quick-answer" style="background:#eff6ff;border-left:4px solid #3b82f6;padding:1rem;margin:1.5rem 0;border-radius:8px 0 0 8px;">
  <strong>被削材不明の場合：</strong>まず「開始 80、出口 400〜800」の 2 点だけ固定し、試作ロットで結果を見て段階を調整してください。金属種を共有いただければ推奨グレードを提示します。

<h2>よくある質問</h2>
<p><strong>被削材で砥粒は変わりますか。</strong>変わります。軟鋼は切りやすく、ステンレスは鈍化が早いため、砥粒タイプとグレード帯を金属種ごとに決めます。</p>
<p><strong>開始点はどのグレードにしますか。</strong>大半の中型仕上げ作業ではグレード 80 から始めるのが妥当です。荒い素材は 40〜60、面出し済みは 120 以上から入ります。</p>
<p><strong>アルミ合金に向きますか。</strong>向きますが砥粒詰まりに注意が必要です。被削材の金属種を共有いただくと推奨を提示します。</p>
