<p class="bluf"><strong>結論：</strong>東北の造船・船舶メンテナンス向けの研磨材適合は、「受入基準を造船所側で先に固定する」ことではじまります。等級区分・砥粒材料・表示要件の 3 点を受入側で決めておくと、中国工場からの出荷（海上 7〜15 日）を受けた造船所での照合が 1 回で通ります。最終適合は輸入者の責任範囲で、造船所が受入主体の場合、受入基準の属するのは造船所自身です。</p>

<h2>造船所の受入検査項目</h2>
<p>造船所が中国工場からの納品で確認するのは、出荷側の品質保証プロセスと並ぶ別軸の検査項目です。工程ごとに砥粒帯が変わるため、検査項目も工程単位で組むのが実務的です。</p>
<table class="spec-table">
  <thead><tr><th>検査項目</th><th>造船所での確認</th><th>出荷側の対応</th></tr></thead>

    <tr><td>等級区分の統一</td><td>JIS / JANSI / FEPA / ISO 6344 を 1 区分に固定</td><td>包装表示に区分を明記</td></tr>
    <tr><td>砥粒材料の系統</td><td>酸化アルミニウム / ジルコニアアルミナの系統確認</td><td>砥粒タイプを仕様確認で合意</td></tr>

<h2>等級区分の採用をどう決めるか</h2>
<p>造船所で砥粒サイズは FEPA P / JIS / ISO 6344 で区分され、JANSI は研磨材の業界規格に位置づけられます。採用区分は受入側の基準で 1 つに固定し、固定した区分を中国工場の仕様確認に伝えます。区分の参照先は<a href="https://www.jisc.go.jp">JISC（一般社団法人 日本規格協会）</a>です。造船所では塗装・錆除去に粗目 40〜80、平滑化に 100〜180 が目安とされ、砥粒タイプ（酸化アルミニウム / ジルコニアアルミナ）は錆タイプと加工方法を確認してから推奨します。工程整理は<a href="/industries/shipbuilding">造船・船舶メンテナンス 業界ページ</a>に、寸法・砥粒の技術仕様は<a href="/technical-specs">技術仕様</a>にあります。</p>

<div class="info-box quick-answer" style="background:#eff6ff;border-left:4px solid #3b82f6;padding:1rem;margin:1.5rem 0;border-radius:8px 0 0 8px;">
  <strong>適合の 2 前提：</strong>① 中国工場から海上 7〜15 日で出荷し、東北に当地の在庫・拠点・法人・専属代理店はない ② 最終適合は輸入者の責任範囲。造船所の作業は個人用保護具・集じん・製品ラベルの遵守が前提で、機構は機械マニュアルに従います。
</div>

<h2>造船所の受入基準を組み立てる手順</h2>
<ol>
  <li>造船所の受入基準で等級区分（JIS / JANSI / FEPA / ISO 6344）を 1 つに固定。</li>
  <li>錆タイプ別に砥粒材料の系統（酸化アルミニウム / ジルコニアアルミナ）を確定。</li>
  <li>溶接手処理・防錆塗装前の注意表示と等級表示を包装図面に反映。</li>
  <li>受入検査で等級区分・砥粒材料・表示の照合を実施。出荷側の確認工程は<a href="/quality">品質保証プロセス</a>を参照。</li>
</ol>

<h2>よくある質問</h2>
<p><strong>造船所で等級区分はどう採用しますか。</strong>受入側の基準で 1 区分に固定します。造船所では粗目 40〜80 で錆除去を、平滑化に 100〜180 が目安。固定した区分は仕様確認に出荷側に伝えます。</p>
<p><strong>砥粒材料の確認で見る点は。</strong>酸化アルミニウムとジルコニアアルミナの系統、錆タイプと加工方法との対応を確認します。被削材の硬度に応じて系統を確定します。</p>
