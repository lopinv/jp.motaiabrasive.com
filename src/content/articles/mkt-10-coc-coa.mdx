<p class="bluf"><strong>結論：</strong>品質保証の業界常識は「COC / COA / ロット管理」の 3 点で決まり、それぞれが規格・基準と関わる点が 1 つずつあります。中部の受入基準では、証書の種類・等級区分・ロット区分の 3 項目を案件単位で先に揃えると、受入検査の往復が減ります。</p>

<h2>3 項目と規格・基準の関わり</h2>
<p>COC・COA・ロット管理の 3 項目は規格・基準と関わる点が 1 つずつあります。関わり方が分かっていないと、証書だけ追加して等級の表記が揃わず、受入で照合不能になります。</p>
<table class="spec-table">
  <thead><tr><th>項目</th><th>定義</th><th>規格・基準との関わり</th></tr></thead>
  <tbody>
    <tr><td>適合証明書（COC）</td><td>製品が仕様通りであることの確認</td><td>仕様（等級・寸法・基材）の表記基準</td></tr>
    <tr><td>分析証明書（COA）</td><td>ロットの検査結果の詳細</td><td>検査項目と等級区分（FEPA / JIS / ISO 6344）</td></tr>
    <tr><td>ロット管理</td><td>数量・砥粒・出荷先の追跡</td><td>ロット区分と追跡単位の統一</td></tr>
  </tbody>
</table>

<h2>受入基準の 3 項目</h2>
<p>中部の受入基準で先に揃えるべきは 3 項目です。等級区分は FEPA / JIS / ISO 6344 のどれで統一するか、ロット区分は数量ロット単位か出荷先単位か、証書は COC / COA のどちらかを、案件単位で確定します。等級区分の整理は<a href="/resources">リソース一覧</a>の砥粒度選定ガイドを参照し、区分自体は<a href="https://www.iso.org">ISO（国際標準化機構）</a>の公開区分を確認します。品質保証プロセスの全体は<a href="/quality">品質保証プロセス</a>にあります。</p>

<div class="info-box quick-answer" style="background:#eff6ff;border-left:4px solid #3b82f6;padding:1rem;margin:1.5rem 0;border-radius:8px 0 0 8px;">
  <strong>3 項目の確定順：</strong>① 等級区分（FEPA / JIS / ISO 6344 のいずれか 1 つ）② ロット区分（数量ロット単位 / 出荷先単位）③ 証書（COC / COA の要否）。この順で確定すると、確定が遅い項目が下の項目の再確認を引き起こしにくくなります。
</div>

<h2>確認フローの整理</h2>
<ol>
  <li>等級区分を受入側の基準に合わせて 1 つに統一。</li>
  <li>ロット区分（数量ロット / 出荷先）を確定。</li>
  <li>証書要件（COC / COA）を案件単位で指定。</li>
  <li>納品とドキュメント段で証書提供とロット情報の追跡を確認。</li>
</ol>
<p>出荷・ドキュメントの基準は<a href="/shipping-oem">出荷とOEM対応</a>に記載しています。</p>

<h2>よくある質問</h2>
<p><strong>COC と COA は両方必要ですか。</strong>必要なのは受入基準で決まります。COC は仕様通りの確認、COA はロットの検査結果の詳細です。案件単位で要否を確定します。</p>
<p><strong>ロット区分を細かくすると何が変わりますか。</strong>追跡精度が上がりますが、包装とドキュメントの手間が増えます。数量ロット単位か出荷先単位のどちらかに絞るのが実務的です。</p>
