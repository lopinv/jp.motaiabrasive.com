<p class="bluf"><strong>結論：</strong>木材板材の面仕上げで速度と品質が同時に崩れる原因は、目数・圧力・送り出しの 3 つが工程ごとに固定されていないことです。工程ごとに 3 つを固定し、固定した値から動いた面を検査して戻す運用にすると、速度を落とさずに品質も安定します。</p>

<h2>目数シーケンスで工程を 3 段に切分する</h2>
<p>板材の面仕上げは「平らげる → 均す → 追い込む」の 3 段に切ると、どの工程で品質が崩れたかの特定が容易になります。各段の砥粒帯は上表の通りで、段間の飛躍が大きすぎると前段の傷が浮き上がるため、隣接段で重ねる運用が手戻りを減らします。</p>
<table class="spec-table">
  <thead><tr><th>段</th><th>砥粒帯（目安）</th><th>役割</th><th>出口条件</th></tr></thead>
  <tbody>
    <tr><td>1 段目</td><td>40〜80</td><td>旧塗装・荒れ・面全体の平らげ</td><td>深い傷と凸凹の除去完了</td></tr>
    <tr><td>2 段目</td><td>100〜180</td><td>面全体の均一化</td><td>傷の方向が一本化・濃淡が均一</td></tr>
    <tr><td>3 段目</td><td>240〜320</td><td>塗装前の追い込み</td><td>斜め光で前段の傷が見えない</td></tr>
  </tbody>
</table>
<p><a href="/resources/abrasive-grit-guide">砥粒度選定ガイド</a>の段階分けと照合して、どの段で止めるか（塗装前までか、無塗装の素地か）を決めておくと、段の切り分けが迷わなくなります。</p>

<h2>速度を落とさず品質を守る 3 つの固定</h2>
<p>速度の源泉は送り出し速度と回転数ですが、いずれも機械側の値であるため、こちらで管理できるのは「圧力」と「目数」の固定です。</p>
<ul>
  <li><strong>圧力の固定：</strong>同じ段内では圧力を一定にします。圧力が強い面ほど除去量が多く、隣接面との高さが変わります。手作業の段はブロックの重さのみで押し、機械の段は一定の押し付けで走行させます。</li>
  <li><strong>目数の固定：</strong>1 段の中で目数を上げ下げすると、傷の方向が混ざり品質判定ができません。1 段 1 目数（必要なら隣接 2 目数まで）に限定します。</li>
  <li><strong>切り替えの固定：</strong>段が変わったら工具を交換し、前段の工具の残り傷を次段の工具で確認してから量産に入ります。</li>
</ul>
<p>木材は圧力の集中で焦げ付きのリスクがあり、速度と圧力を同時に上げた場合は必ず小面積で試してから全幅に入ってください。作業時は集じん設備と PPE（保護眼鏡・耳栓・マスク）を必ず使用します。</p>

<h2>工程間の検査と、品質が崩れたときの戻し方</h2>
<p>各段の出口では斜め光（光源を面に平行方向から当てる方法）で傷の方向と濃淡を確認します。方向が一本になっていない面は前段に戻し、濃淡が均一でない面は同段内で圧力を揃え直します。戻す工程が常に「1 つ手前」に限定できるか、が工程設計の出来不出来を測る指針になります。</p>

<p><strong>納品について（全国）：</strong>各主要港（東京・大阪・神戸・仙台・名古屋・広島・北九州等）への納品は中国工場からの出荷となり、海上輸送で 7〜15 日を見てください。日本国内に在庫・拠点・法人・専属代理店を持たず、最終的な規格適合の判断は輸入者責任となります。</p>

<div class="info-box quick-answer" style="background:#eff6ff;border-left:4px solid #3b82f6;padding:1rem;margin:1.5rem 0;border-radius:8px 0 0 8px;">
  <strong>最短で確認する 1 面：</strong>段 1 の 80 → 段 2 の 150 → 段 3 の 240 と 1 面ずつ進め、斜め光で段ごとに検査。どの段で品質が崩れるかが分かれば、速度・圧力・目数のどれかを固定し直す対象が定まります。
</div>

<h2>よくある質問</h2>
<p><strong>板材の面仕上げはどの目数から始める？</strong>表面の荒れ具合で決まります。平らげからなら 40〜80 帯、ほぼ平らなら 100〜180 帯から。詳細は<a href="/products/abrasive-belts">研磨ベルト 製品一覧</a>の目数帯と照合してください。</p>
<p><strong>1 本のベルトで全工程を回せますか。</strong>サイズが機械に合っていれば、目数を変えて工程を組めます。消耗量は数量確認時に試算します。</p>
<p><strong>速度を上げると品質は必ず落ちますか。</strong>送り出し・圧力・目数の組み合わせ次第です。焦げ付きのリスクは上がるため、速度変更時は小面積で試します。</p>
