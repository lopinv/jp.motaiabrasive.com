<p class="bluf"><strong>結論：</strong>関東での研磨材調達の法規制・適合（JIS/JANSI）は、「等級区分の統一→砥粒材料の確認→表示要件の確認」の 3 段で整います。中国工場からの出荷（海上 7〜15 日）を前提にする場合、最終適合は輸入者の責任範囲になるため、受入側の基準を先に固定しておくと適合確認の往復が減ります。</p>

<h2>適合確認の 3 段</h2>
<p>関東の受入基準で確認するのは 3 段です。段の順で確定すると、段を飛ばした時の再確認が減ります。</p>
<table class="spec-table">
  <thead><tr><th>段</th><th>確認項目</th><th>区分の整理</th></tr></thead>
  <tbody>
    <tr><td>1</td><td>等級区分の統一（JIS / JANSI / FEPA / ISO 6344）</td><td>受入側の基準で 1 区分に固定</td></tr>
    <tr><td>2</td><td>砥粒材料の系統</td><td>酸化アルミニウム / ジルコニアアルミナ / セラミック砥粒</td></tr>
    <tr><td>3</td><td>表示要件</td><td>砥粒の等級表示と作業上の注意表示</td></tr>
  </tbody>
</table>

<h2>JIS / JANSI の位置づけ</h2>
<p>砥粒サイズは FEPA P / JIS / ISO 6344 で区分されます。JIS は工業規格、JANSI は研磨材の業界規格に位置づけられ、受入側の基準で採用区分を確定します。区分の参照先は<a href="https://www.jisc.go.jp">JISC（一般社団法人 日本規格協会）</a>です。寸法・砥粒の技術仕様は<a href="/technical-specs">技術仕様</a>に、確認工程の全体は<a href="/quality">品質保証プロセス</a>に記載しています。金属加工の現場用途は<a href="/industries/metalworking">金属仕上げ 業界ページ</a>で補足できます。</p>

<div class="info-box quick-answer" style="background:#eff6ff;border-left:4px solid #3b82f6;padding:1rem;margin:1.5rem 0;border-radius:8px 0 0 8px;">
  <strong>適合の 2 前提：</strong>① 出荷は中国工場から（海上 7〜15 日）で、関東に当地の在庫・拠点・法人・専属代理店はない ② 最終適合は輸入者の責任範囲。等級区分を先に固定すると、受入検査の照合が簡潔になります。
</div>

<h2>受入基準の整理手順</h2>
<ol>
  <li>等級区分（JIS / JANSI / FEPA / ISO 6344）を受入側の基準で 1 つに固定。</li>
  <li>砥粒材料の系統（酸化アルミニウム / ジルコニアアルミナ / セラミック砥粒）を用途で確定。</li>
  <li>表示要件（等級表示・注意表示）を包装図面に反映。</li>
  <li>受入検査で等級区分と砥粒材料の照合を実施。</li>
</ol>
