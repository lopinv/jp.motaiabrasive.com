<p class="bluf"><strong>結論：</strong>1520×630 mm は幅 630 mm の大型ベルト機を前提にしたモデルで、向く用途と向かない用途の境界は明確です。重負荷の板材研削・金属エッジ準備に向き、手持ち工具や超仕上げには向きません。砥粒 40〜320 の 9 グレードが「研削と仕上げに集中し、超仕上げは別工具」という設計思想そのもので、発注前にこの境界を理解しておくことで不適合を避けられます。</p>

<h2>向く用途：大型機が前提の 3 場面</h2>
<ul>
  <li><strong>大型木材板材の仕上げ：</strong>幅 630 mm が 1 回でカバーするため、ライン速度を落とさず搬送できます。</li>
  <li><strong>工業用木材の製造：</strong>安定した定期供給ロットの梱包に対応し、消費が定常のラインで効きます。</li>
  <li><strong>金属エッジの準備：</strong>石油・ガス分野の表面準備（パイプ錆除去、タンク面処理）のような重負荷作業と噛み合います。全体像は<a href="/industries/oil-gas">石油・ガス向けソリューション</a>に。</li>
</ul>

<h2>向かない用途：3 つの境界線</h2>
<p>次の 3 点はこのモデルの適用外として、最初に切り捨てるべきです。</p>
<ul>
  <li><strong>手持ち工具：</strong>幅 630 mm を扱う大型機が必要なため通常できません。</li>
  <li><strong>超仕上げ工程：</strong>砥粒範囲が 40〜320 で止まるため、仕上げの最終段階は別の工具で行う設計になります。</li>
  <li><strong>幅の限られた機械：</strong>610×100 mm や 915×100 mm を扱う中型機に載せることはできません。機械の対応幅から逆算してください。</li>
</ul>

<h2>砥粒 40〜320 をどう読む</h2>
<p>9 グレード（40 / 60 / 80 / 100 / 120 / 150 / 180 / 240 / 320）は粗研ぎ帯 40〜100、面出し帯 120〜240、仕上げ帯 320 に分配されます。これは大型機が「厚い層の除去と均一化」を主業務とするため、細目帯を意図的に削った設計です。段階の割り当て方そのものは <a href="/resources/abrasive-grit-guide">砥粒度選定ガイド</a>を参照してください。粒度呼びは FEPA の P グレードが国際的な基準の一つとして使われます。</p>

<div class="info-box quick-answer" style="background:#eff6ff;border-left:4px solid #3b82f6;padding:1rem;margin:1.5rem 0;border-radius:8px 0 0 8px;">
  <strong>選び方の 1 行：</strong>幅 630 mm の大型ベルト機があり、厚い層の除去・重負荷研削が主目的なら 1520×630 mm。手持ち機・超仕上げ・幅 100〜150 mm の機械なら別サイズです。
</div>
