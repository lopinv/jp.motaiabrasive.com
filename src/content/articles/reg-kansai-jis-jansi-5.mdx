<p class="bluf"><strong>結論：</strong>関西の造船向け研磨材調達の法規制・適合（JIS/JANSI）は、造船所・海洋工事で「等級区分→砥粒材料→表示要件」の順で整えます。中国工場からの出荷（海上 7〜15 日）を前提にする場合、造船所の受入基準（溶接処理・防錆塗装前の準備を含む）を先に固定すると、適合確認の手順が 1 回で通ります。最終適合は輸入者の責任範囲です。</p>

<h2>造船所受入の 3 段</h2>
<p>造船所の受入で確認するのは 3 段です。造船所では工程（錆除去→溶接手処理→塗装前準備）ごとに砥粒帯が変わるため、段ごとに区分と要件を分けて確認します。</p>
<table class="spec-table">
  <thead><tr><th>段</th><th>確認項目</th><th>造船所での整理</th></tr></thead>
  <tbody>
    <tr><td>1</td><td>等級区分の統一（JIS / JANSI / FEPA / ISO 6344）</td><td>受入側の基準で 1 区分に固定</td></tr>
    <tr><td>2</td><td>砥粒材料の系統</td><td>酸化アルミニウム / ジルコニアアルミナを錆タイプで選定</td></tr>
    <tr><td>3</td><td>表示要件</td><td>等級表示と溶接手処理の注意表示</td></tr>
  </tbody>
</table>

<h2>造船所の工程と砥粒帯</h2>
<p>造船所の表面準備は鋼板の錆除去と旧塗装剥離から始まり、溶接手処理、塗装前表面処理、表面摩擦低減へと続きます。砥粒は塗装・錆除去に粗目 40〜80、その後平滑化に 100〜180 が目安とされ、砥粒タイプ（酸化アルミニウム / ジルコニアアルミナ）は錆タイプと加工方法を確認してから推奨します。工程の整理は<a href="/industries/shipbuilding">造船・船舶メンテナンス 業界ページ</a>に、寸法・砥粒の技術仕様は<a href="/technical-specs">技術仕様</a>に記載しています。区分の参照先は<a href="https://www.jisc.go.jp">JISC（一般社団法人 日本規格協会）</a>です。</p>

<div class="info-box quick-answer" style="background:#eff6ff;border-left:4px solid #3b82f6;padding:1rem;margin:1.5rem 0;border-radius:8px 0 0 8px;">
  <strong>造船所での 2 前提：</strong>① 出荷は中国工場から（海上 7〜15 日）で、関西に当地の在庫・拠点・法人・専属代理店はない ② 最終適合は輸入者の責任範囲。等級区分を造船所の受入基準で先に固定すると、溶接手処理・塗装前準備の照合が簡潔になります。
</div>

<h2>適合確認の手順</h2>
<ol>
  <li>造船所の受入基準で採用する等級区分（JIS / JANSI / FEPA / ISO 6344）を 1 つに固定。</li>
  <li>錆タイプ別に砥粒材料の系統（酸化アルミニウム / ジルコニアアルミナ）を確定。</li>
  <li>溶接手処理・防錆塗装前の注意表示を包装図面に反映。</li>
  <li>確認工程は品質保証プロセス（<a href="/quality">品質保証プロセス</a>）の 5 段に沿って実施。</li>
</ol>

<h2>よくある質問</h2>
<p><strong>造船向けの砥粒材料はどの系統ですか。</strong>酸化アルミニウムとジルコニアアルミナが中心で、錆タイプと加工方法を確認してから推奨します。被削材の硬度に応じて系統を選択します。</p>
