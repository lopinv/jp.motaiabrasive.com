<div dir="ltr" lang="ja">

<p class="bluf"><strong>結論：</strong>ANSI と FEPA P は同じ数字が同じ粒径を指さない粒度体系です。発注書と受入書（COC）で体系を統一しなければ、届いた砥粒の粒度と現場の想定がずれます。石油・ガス分野の表面準備のように後工程（塗装・検査）が厳格なほど、体系未定は手戻りに直結します。</p>

<h2>3 体系の位置づけ</h2>
<p>日本市場では JIS（日本工業規格）、欧州市場では FEPA P 記号、米国市場では ANSI が使われます。いずれも砥粒を粒度帯に区分する体系ですが、数値の振れ方は体系ごとに異なり、細目に行くほど差が広がります。そのため「180 で発注」だけでは仕様として不確定で、体系と粒度帯の許容幅まで書かないと受入基準が作れません。</p>

<h2>受入で確認する粒度の読み方</h2>
<p>粒度の読み方は、製品ラベルの粒度表記を <a href="/quality">品質管理・検査体制</a> の受入項目として扱うことから始まります。確認すべきは 3 点です。</p>
<ul>
  <li><strong>体系：</strong>表記が P（FEPA）か ANSI か JIS か。体系名のみの表記は不十分。</li>
  <li><strong>粒度帯の幅：</strong>同一数字でも体系ごとの粒径範囲が異なるため、受入許容幅を事前に確定する。</li>
  <li><strong>ロット一致：</strong>COC の粒度表記がロット単位で追跡可能か。ロット混在の受け入れは品質ばらつきの原因。</li>
</ul>

<h2>石油・ガス用途での落とし所</h2>
<p><a href="/industries/oil-gas">石油・ガス分野</a>の配管・タンク表面準備は、後工程の塗装が粒度のずれに敏感です。粒度体系が統一されたロットで発注し、COC で粒度表記を突き合わせる運用が、現場での品質安定に繋がります。体系の読み替えが必要な場合は、<a href="/resources/abrasive-grit-guide">砥粒度選定ガイド</a> の体系別項目を参照のうえ、数量と受入時期とあわせて <a href="/quote">見積依頼フォーム</a> で照会してください。標準の粒度区分の最新情報は FEPA（<a href="https://www.fepa-abrasives.org">FEPA</a>）の公表資料を参照してください。</p>

<div class="info-box quick-answer" style="background:#eff6ff;border-left:4px solid #3b82f6;padding:1rem;margin:1.5rem 0;border-radius:8px 0 0 8px;">
  <strong>受入前に：</strong>発注書と COC の粒度表記（体系＋目数＋許容幅）が一致するか。体系不明のロットは受入停止。
</div>

<h2>よくある質問</h2>
<p><strong>FEPA P と ANSI は何がちがいますか。</strong>同じ数値でも粒径帯が異なり、特に細目側で差が広がります。発注書と COC の粒度表記が同じ体系かを照合してください。</p>
<p><strong>既存の ANSI 指定を FEPA 相当で発注できますか。</strong>可能です。体系の読み替えは発注時に照合し、粒度帯の許容幅を双方で確認のうえ確定します。</p>
<p><strong>粒度ずれが出たときの再発防止は。</strong>ロット毎の COC と受入検査記録を残し、体系未定ロットの受け入れを管理ルールとして禁止する。受入設計は品質ページで確認できます。</p>
