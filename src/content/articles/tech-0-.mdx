<p class="bluf"><strong>結論：</strong>砥粒種は「何を削るか」で決める変数です。木工の素研ぎ・中仕上げは酸化アルミニウムが主力で、塗膜や接着剤の除去・滑らか仕上げは炭化シリコンが効く、という 2 系統の性格の違いを軸に工具を選べば、目数選びの手戻りが減ります。</p>

<h2>2 系統の削り方の違い</h2>
<p>酸化アルミニウム（アルミナ）は硬度がが高く、砥粒の刃が鋭く保持されるため、硬めの木材の素研ぎから中仕上げまで幅広く使われる汎用の砥粒です。木工・家具製造の標準的な研削工程では、まずこれが出てきます。一方、炭化シリコン（SiC）はさらに硬く刃が細く、軟らかい被削材（塗膜、接着剤、柔らかい材）で詰まりにくく滑らかな面を作る傾向があります。どちらか一方が優れているのではなく、被削材と目的で役割が分かれているのが実態です。</p>

<h2>目数帯との組合せ方</h2>
<p>砥粒種と目数帯は独立して決める変数ではありません。同じ 120 でもアルミナと SiC では詰まりやすさと面感が変わります。木工の <a href="/industries/woodworking">現場</a> では、次の順で落とすのが実務的です。</p>
<ol>
  <li><strong>用途を確定：</strong>研削（厚く取る）か、中仕上げ、超仕上げか。</li>
  <li><strong>被削材を確定：</strong>木材そのものか、塗膜・接着剤を含む面か。</li>
  <li><strong>砥粒種を確定：</strong>木材の素研ぎはアルミナ、塗膜除去〜超仕上げは SiC を検討。</li>
  <li><strong>目数帯を確定：</strong>工具の規格（<a href="/products/abrasive-belts">研磨ベルト製品一覧</a> では 40〜800 の帯、ディスクでは 60〜5000 の帯を扱い）の中で、工程に合う目数を選びます。</li>
</ol>
<p>目数体系（FEPA P 等）の読み方は <a href="/resources/abrasive-grit-guide">砥粒度選定ガイド</a> とあわせて参照してください。粒度区分の最新情報は <a href="https://www.fepa-abrasives.org">FEPA</a> の公表資料が参照先です。</p>

<h2>工具形状との組合せと発注の落とし所</h2>
<p>同じ砥粒種でも工具形状（ベルト・ディスク・スポンジ）で使える工程が変わります。広い面の素研ぎはベルト、平面の追いはディスク、角・細部はスポンジが基本の分業です。どの工具にどの砥粒種・目数を組み合わせるかは発注時に確定する事項なので、数量とあわせて <a href="/quote">見積依頼フォーム</a> に書いてください。砥粒種と目数の組合せ候補については、サンプル評価の運用として品質ページで確認できます。</p>

<div class="info-box quick-answer" style="background:#eff6ff;border-left:4px solid #3b82f6;padding:1rem;margin:1.5rem 0;border-radius:8px 0 0 8px;">
  <strong>1 行の選び方：</strong>木材の素研ぎ・中仕上げ→酸化アルミニウム。塗膜・接着剤の除去と超仕上げ→炭化シリコン。迷ったら用途と被削材を先に入れる。
</div>

<h2>よくある質問</h2>
<p><strong>酸化アルミニウムと炭化シリコンは何が違いますか。</strong>酸化アルミニウム（アルミナ）は硬度が高く切削が鋭く、木材の素研ぎから中仕上げまで広く使われる汎用の砥粒です。炭化シリコン（SiC）はより硬く鋭く、軟らかい塗膜・接着剤・塗装面への除去や滑らかな仕上げに向く特性を持ちます。</p>
<p><strong>木工ではどちらを選ぶのが一般的ですか。</strong>素研ぎ・中仕上げの研削は酸化アルミニウムが基本です。塗装面の除去や超仕上げで詰まりにくく滑らかな面が要る場合は炭化シリコンを検討します。対象材（軟調材・硬質材）で使い分けは変わります。</p>
<p><strong>目数帯と砥粒種は独立して選べますか。</strong>独立では決まりません。同じ目数でも砥粒種で削り味・詰まりやすさ・面感が変わります。用途（研削か仕上げか）と被削材を先に決め、そのうえで目数帯を落とすのが手戻りの少ない手順です。</p>
